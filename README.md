# JBNU Agricultural Hydrology Lab

GitHub Pages에 바로 게시할 수 있도록 `index.html`을 저장소 최상위에 둔 정적 웹사이트입니다.

## 처음 게시하기

1. GitHub Desktop에서 `File > Add local repository`를 선택합니다.
2. 이 폴더를 선택하고 `create a repository`를 누릅니다.
3. 저장소 이름을 `jbnu-hydrology-lab`로 지정합니다.
4. `Publish repository`를 누릅니다. 무료 GitHub Pages를 사용할 경우 공개 저장소로 게시합니다.
5. GitHub 웹사이트의 저장소에서 `Settings > Pages`로 이동합니다.
6. `Source`를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/(root)`로 지정하고 저장합니다.

## 이후 수정하기

1. VS Code에서 파일을 수정하고 저장합니다.
2. GitHub Desktop에서 변경 내용을 확인합니다.
3. 왼쪽 아래 Summary에 변경 내용을 적고 `Commit to main`을 누릅니다.
4. 상단의 `Push origin`을 누릅니다.

## 주요 파일

- `index.html`: 문구, 연구과제, 논문, 구성원 등 페이지 내용
- `assets/styles.css`: 색상, 글꼴, 크기, 배치, 모바일 디자인
- `assets/script.js`: 모바일 메뉴, 스크롤 효과, 논문 펼치기 기능
- `assets/`: 사이트에서 사용하는 이미지
